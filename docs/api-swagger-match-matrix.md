## 安全不变量与检查口径

- ID/订单号作为不透明值，回传/比较/关联不做Number转换；时间与明确数量字段可在adapter规范；金额比较按精确十进制处理，人民币仍仅参考。
- confirmedAmount按本次原订单集合核对，剩余单确认不重付已付款单；逐单失败与-312保留可核对结果。
- 资金/退款只有成功响应显式data:null才进入原键重试资格；缺data、错金额/归属、旧无键、成功却查空均不自动重发。每次重试重新确认原参数与当前条件，成功与刷新失败分开。
- 页面/账号/筛选代次防迟到响应；存储失败不当空记录；接口业务失败不回退Mock。-311/-312不冒充登出；仅明确部署诊断收敛展示，kind/code/statusCode保留。
- KYC配置驱动而非护照硬编码例外；新schema不得删除旧待核对回执。IM分页显式markRead:false，实际可见底部才标读。
- 本次提交检查已通过：pnpm typecheck、pnpm build:h5、pnpm build:app-plus、现有共享契约脚本、git diff --check；求购隔离修正后重跑通过。当前源码RequestError临时进程7项检查通过；新增内容敏感模式扫描无命中，本地配置/依赖未混入。App构建不等于真机验收，准确提交与远端同步状态以 Git HEAD 和远端分支为准，不代表部署或完整业务验收。
- 不新增测试、临时脚本、Mock样本、依赖或其他仓库修改；旧日期快照和重复过程合并。未闭环的资金、KYC、物流、媒体、样本及工具限制继续保留，不按旧百分比宣称全部完成。

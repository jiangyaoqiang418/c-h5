```bash
git switch main
git pull --ff-only origin main
pnpm install
pnpm typecheck
```

随后按顺序读取：

1. `AGENTS.md`
2. `README.md`
3. `docs/p2-handoff.md`
4. `docs/api-integration-plan.md`

## 已确认边界

- 已迁移模块禁止真实请求失败后回退 Mock。
- 真实 Long/int64 ID 必须保留字符串或原始值，不使用 `Number()`、`parseInt()` 做 API 参数转换。
- 综合商品筛选列表继续使用 Mock；首页真实商品通过 `source=real` 进入真实详情，不进入旧 Mock 购物车和订单链。
- 积分规则继续使用 Mock，因为当前只有 admin 读取能力，未确认 C 端契约。
- 订单、结算和完整售后继续保留 Mock，等待 `docs/order-contract-confirmation.md` 中的后端问题确认。
- H5 开发和部署使用同源 `/api/*`；Android/iOS 需要完整 HTTPS 服务地址。

## 建议继续顺序

1. 获得无申请账号和 KYC 已通过买手账号，完成任务 2、3 的写入回归。
2. 准备至少一个在售商品，完成任务 4 首页、公开详情和浏览打点回归。
3. 准备非空资金记录与可申诉扣分流水，完成任务 5、7 的非空和分页回归。
4. 后端定位充值创建失败后恢复任务 6。
5. 后端更新订单 Swagger 后重新评估任务 8，未更新前不得迁移订单页面。

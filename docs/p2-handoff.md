## 已确认边界

- 已迁移模块禁止真实请求失败后回退 Mock。
- 真实 Long/int64 ID 必须保留字符串或原始值，不使用 `Number()`、`parseInt()` 做 API 参数转换。
- 综合商品筛选列表继续使用 Mock；首页真实商品通过 `source=real` 进入真实详情，不进入旧 Mock 购物车和订单链。
- 积分规则继续使用 Mock，因为当前只有 admin 读取能力，未确认 C 端契约。
- 订单、结算和完整售后继续保留 Mock，等待 `docs/order-contract-confirmation.md` 中的后端问题确认。
- H5 开发和部署使用同源 `/api/*`；Android/iOS 需要完整 HTTPS 服务地址。

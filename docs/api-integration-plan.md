## Mock 与交付边界

- 已接入真实接口的模块请求失败时不得回退 Mock，也不得伪造成功状态。
- 未迁移模块可以维持现有 `@shared` Mock；CMS、AI 和演示数据只能计为页面交互，不能计入真实接口验收。
- H5 开发与部署使用同源 `/api/*` 代理；Android/iOS 仅使用 HTTPS 服务地址，不依赖 H5 代理或浏览器能力。
- H5 为当前先行验收端；Android/iOS 在模块里程碑集中验证安全区、软键盘、返回、滚动、固定操作栏和错误提示。

## 接口接入原则

1. 修改前刷新对应 live Swagger，递归核对路径、方法、参数、必填项、requestBody、response 与嵌套 schema。
2. 页面交互保持现状；路径、字段、类型、枚举、分页与响应结构以当前有效契约为准。
3. 字段差异只在 `src/service/api/` 或 adapter 边界转换，不将后端 DTO 扩散到页面。
4. 所有业务 ID 按不透明 Long 原值处理，页面层禁止 `Number()`、`parseInt()` 或算术转换。
5. 分开记录“Swagger 存在、API 已封装、页面已调用、真实数据已验证”，任一层不能替代另一层。
6. 真实接口失败必须展示真实失败、权限或空态，不自动 fallback Mock。
7. TypeScript/公共逻辑变化运行 `pnpm typecheck`；构建、环境或跨端基础能力变化运行对应构建；页面交互使用 Chrome 移动视图回归。
